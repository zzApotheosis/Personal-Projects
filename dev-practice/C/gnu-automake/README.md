# GNU Automake

This is a demonstration package for GNU Automake.
Type `info automake` to read the Automake manual.

## Example Steps

Run these steps to get a feel for [GNU Automake](https://www.gnu.org/software/automake/).

> $ tar -xzvf amhello.tar.gz  
> $ autoreconf --install --force  
> $ ./configure  
> $ make  
> $ ./src/hello
