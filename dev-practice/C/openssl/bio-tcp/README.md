# OpenSSL Example

This is a very basic example for an OpenSSL implementation.

## Building and running this example

> `$ ./cert-gen.sh`  
> `$ ./build.sh`  
> `$ ./.destdir/usr/local/bin/openssl-example-server 8080 cert.pem key.pem`  
> In a different terminal: `$ ./.destdir/usr/local/bin/openssl-example-client localhost 8080 cert.pem`
