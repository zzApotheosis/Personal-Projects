## Disclaimer

A lot of this example code was written with Zig version 0.14.0 and the standard library has drastically changed since this code was written.
Many examples will probably not compile, but they can still serve as good syntax/semantics examples. Eventually I'll spend the time to
update the examples to the latest stable Zig version.
